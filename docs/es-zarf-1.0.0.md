# ZARF's Spanish Translation mod 1.0

Spanish translation by **ZARF (MOD-ZARF / MODZARF)**, adapted for Def Jam Recompiled.
Original translation: [ZARF's project](https://github.com/MODZARF/Parche-textos-en-espanol-DJFFNY-Compatible-con-Xbox-360).

- Spanish menu, HUD, Story/subtitle and memory-unit text, with extended subtitle accents.
- 158 unique 4× recreated HD Spanish textures covering 177 changed archive slots.
- Original-game/HD typography, protected stamp frames and illustrations, and a
  localized widescreen main-menu wall. HD Widescreen Menus and HD Fighters remain optional.
- 28 unchanged conversion deltas rebuild the translated resources from the player's
  supported USA dump. No original game archives, XBE or executable is distributed.
- Original voices remain unchanged. Enable one language at a time; disable and
  restart Play to return to English.

Requires **game 0.13.0 or later**. Open Mods, Refresh, Install, tick the installed
language mod and Play. Installation alone does not enable it. The pack's own HD
images load even with separate texture packs disabled.
