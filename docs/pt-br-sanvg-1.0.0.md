# Portuguese (Brazil) Translation 1.0

Brazilian Portuguese translation for Def Jam Recompiled, published on Thunderstore by
**JJalesTeam**: <https://thunderstore.io/c/def-jam-fight-for-ny-recompiled/p/JJalesTeam/Portuguese_Translation/>.

## What it changes

- Menus, Story subtitles, memory-unit messages and Portuguese accents in five game fonts.
- 193 recreated 4× HD textures and translated widescreen menu art.
- Voice subtitles (`speech_subtitles.txt`) for fighter intros and victories, shops, the tutorial and
  voicemail. They need game 1.2.0; the setting is **Interface → Language and subtitles**
  (`[language] voice_subtitles`).
- The pack replaces the game's built-in French slot (`base=french`), so the game starts in that slot while
  it is enabled. Voices stay English.

Install it in **Mods**, enable it, then Play. Disable it and restart to return to English. Enable one
language mod at a time.
